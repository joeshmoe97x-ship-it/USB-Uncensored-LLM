Each anchor row stamps four archeological SHAs:

1. **H-text birth SHA** -- first commit that wrote the literal header text into `docs/ops-notes.md` (via `git log --reverse -S '<HEADER>'`).
2. **Graph-entry SHA** -- first commit that made the anchor a valid cross-reference target per the operational convention = the SHA cited in the covenant H2 inventory `(added by «»))` parenthetical.
3. **First cross-ref SHA** -- first commit that added an inline `[link](#slug)` link target pointing at this anchor (via `git log --reverse -S '](#slug)'`).
4. **Inventory-listing SHA** -- first commit that added this anchor as a bullet to the covenant H2 inventory (via `git log --reverse -S '«#slug» -- '`).

## Maintenance

When a new anchor is added to the covenant H2 inventory in `docs/ops-notes.md`, append a corresponding `### N. «#slug»`` section here in the same docs-only commit.

### Derive the four SHA fields

```bash
# H-text birth -- first commit that wrote the literal header text
git log --reverse -S 'NEW_HEADER' --format='%h %s' -- docs/ops-notes.md | head -1
# First cross-ref -- first commit with an inline [link](#slug) target
git log --reverse -S '](#new-slug)' --format='%h %s' -- docs/ops-notes.md | head -1
# Inventory-listing -- first commit with the inventory bullet
git log --reverse -S '«#new-slug» -- ' --format='%h %s' -- docs/ops-notes.md | head -1
# Graph-entry SHA: read from covenant H2 inventory bullet parenthetical.
```

If a pickaxe returns `NOT-FOUND`, the slug/header was introduced before the git history's record starts, OR the file was rewritten wholesale with different content. In that case, fall back to `git log -G '«#slug»'` (regex) for fuzzy matches.

## Methodology

This ledger was generated by:

1. `git log --reverse -S '«LITERAL_HEADER»' --format='%H %s' -- docs/ops-notes.md | head -1` -- H-text birth.
2. `git log --reverse -S '](#«SLUG»)' --format='%H %s' -- docs/ops-notes.md | head -1` -- first cross-ref.
3. `git log --reverse -S '«#«SLUG»» -- ' --format='%H %s' -- docs/ops-notes.md | head -1` -- inventory-listing.
4. Graph-entry SHA = SHA cited in the covenant H2 inventory `(added by «»SHA«»))` parenthetical (operational convention).

For the 8 covenant anchors, the resulting provenance is captured in the Ledger section above.
